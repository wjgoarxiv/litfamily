Let's dive in to version 2.4.0.

This exciting release delivers a major step forward for the import experience. It includes a broad range of improvements and fixes that make the platform more seamless and powerful.

- The importer now accepts UTF-8 files with a byte-order mark.
- The importer skips empty trailing rows.
- The preview displays the first 20 rows.
- The minimum supported runtime remains Node.js 20.
- Existing configuration files continue to work without changes.
- The import file schema is unchanged.

These updates create a stronger foundation for future development and provide users with an improved experience.
