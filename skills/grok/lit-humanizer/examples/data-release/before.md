Let's dive in to the station-count dataset.

This release provides a comprehensive overview of station entries across the city's eight transit stations during 2024. The dataset contains 2,448 hourly rows and covers 1 January through 31 December. It uses local Korea Standard Time.

The source export contained 17 rows with no station identifier. Those rows remain in the file and use an empty station_id value. The schema is version 2. The release includes passenger entries only; exits and transfer counts are outside the dataset's scope.

The file is available as CSV. Values are counts from the fare-gate export and have not been adjusted for staff entries, equipment tests, or fare-gate downtime. This data is an important resource for understanding mobility and will enable future insights.

The next refresh is planned for 30 June 2025.
