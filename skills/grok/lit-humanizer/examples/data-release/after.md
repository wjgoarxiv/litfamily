# 2024 station entries

The CSV contains 2,448 hourly rows for passenger entries at the city's eight transit stations from 1 January through 31 December 2024. Timestamps use Korea Standard Time. The schema version is 2.

Seventeen source rows had no station identifier. They remain in the file with an empty station_id value. The counts come from the fare-gate export and have no adjustments for staff entries, equipment tests, or fare-gate downtime. The file contains entries only; it has no exit or transfer counts.

The next refresh is planned for 30 June 2025.
