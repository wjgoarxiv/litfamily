# LitFamily Ignition artwork

Ignition combines orange, lime and ivory on carbon navy. An interlocking symbol, angular display lettering, ordered halftone and restrained scanlines connect the covers to the terminal B mark. The [gallery](gallery.html) shows six vector covers and matching icons. [File hashes](artifact-manifest.json) identify the distributed files.

SVG masters use authored geometric paths and outlined JetBrains Mono glyphs. They contain no embedded bitmap, raster tracing, font-dependent text, scripts or external resources. No image generation tool was used for this vector revision. The editable production scripts and previous designs are preserved by the maintainer. MARATHON's graphic direction informed the initial aesthetic brief; no game graphics, logos or fonts are redistributed.

Exact palette: ignition orange `#FF6337`, signal lime `#D7F75B`, terminal ivory `#F2EFDF`, carbon navy `#080D14`. [Download the color sheet](exports/lit-palette.svg) or [transparent symbol](exports/lit-wordmark.svg). PNG and lossless WebP are compatibility exports from the same masters; antialiased edges contain intermediate colors. Installation commands remain selectable text. No release version is baked into a cover.

The [10-second Ignition film](exports/ignition-film.mp4) uses authored SVG frames to assemble the interlocking symbol and introduce Plan / Build / Verify. The [GIF](exports/ignition-demo.gif) is an optional compact export; the [static motion poster](exports/ignition-poster.png) avoids animation. This is a brand demonstration, not a recording of installation or host execution. Native terminal policies remain product-specific.

The centered README mark uses outlined JetBrains Mono glyphs; its exact text remains copyable in each README. The three [Lucide](https://github.com/lucide-icons/lucide) icons retain their [ISC license](readme/Lucide-LICENSE.txt); only their stroke color is adapted. Static [Shields](https://shields.io/) badges describe the npm release, MIT license, and five independent ports. They do not claim CI status.

Artwork and documentation follow the repository [MIT license](../../LICENSE). Gallery body text uses bundled JetBrains Mono; SVG lettering is outlined geometry. The supplied fonts retain their SIL Open Font License 1.1 notices: [Space Grotesk](fonts/SpaceGrotesk-OFL.txt) and [JetBrains Mono](fonts/JetBrainsMono-OFL.txt). Exact upstream URLs and hashes are in [font provenance](fonts/provenance.json).

These are local assets. Publication and authenticated host acceptance are separate. Previous covers, terminal artwork and production assets are preserved outside the active distribution by the maintainer.

## v5 armory README covers

The v5 lossless WebP exports in `exports/` are one emphasis cover for each product and `litfamily-armory.webp`, the hub's former top cover, which stays in `exports/` but is no longer shown in the hub READMEs. The hub READMEs show the five emphasis covers; their top image is now the motion cover below. They are 1536×1024 compatibility exports from the accepted v5 master; the exact SHA-256 values are recorded in `artifact-manifest.json`. Product-specific covers are copied into each product's `docs/assets/cover.webp`; the large PNG master stays in this umbrella brand directory. These files do not prove GitHub or npm availability.

## Motion README cover

Both hub READMEs open with `exports/litfamily-cover-motion.webp`, a 960×640 animated WebP that loops about every 11 seconds. From a dark standby, the five robot panels power on one by one, each robot wakes as its eyes and frame glow, and then LITFAMILY and KEEP THE WORK LIT. light up. Readers who ask for reduced motion see `exports/litfamily-cover-motion-still.webp`, the fully lit hold frame. [The 11-second film with sound](exports/litfamily-cover-film.mp4) is the 1920×1080 master. The exact SHA-256 values are recorded in `artifact-manifest.json`. The Ignition film, GIF and poster stay in `exports/`.
